¿Cómo usar estos iconos SVG?

Puedes hacer clic en el botón "Descargar SVG" debajo de cada icono para obtener el archivo individual. Luego, simplemente arrastra y suelta estos archivos SVG en tu presentación (PowerPoint, Google Slides, Keynote, etc.). Mantendrán su calidad sin importar el tamaño y podrás cambiar el color del contorno si lo deseas.

Para cambiar el color del contorno: En la mayoría de los programas de presentación, después de insertar el SVG, puedes seleccionarlo y usar las opciones de "Formato de gráficos" o "Color de línea" para cambiar el color del trazo (stroke) a tu gusto.
