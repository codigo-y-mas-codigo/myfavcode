La Guía Práctica de Animación de Trazos

Bienvenido al laboratorio interactivo de animación de trazos SVG. Descubre la técnica que da vida a iconos, logos y diagramas, haciéndolos dibujarse solos en la pantalla. Una habilidad esencial para el diseño web moderno: elegante, ligera y profesional.

Recetas Interactivas

Explora las técnicas fundamentales. Cada receta incluye una demostración en vivo y el código exacto para que puedas replicarla. ¡Interactúa con los ejemplos para entender la magia!

Pasa el cursor sobre el icono

Receta 1: Efecto Hover Interactivo 🖱️

El gráfico se dibuja cuando el usuario pasa el cursor sobre él. Es el método más simple, basado puramente en CSS, ideal para iconos y botones.

<!-- HTML -->
<svg width="100" height="100">
  <path class="icono-hover" d="..." />
</svg>

<!-- CSS -->
.icono-hover {
  stroke: #3498db;
  stroke-dasharray: 1000;
  stroke-dashoffset: 1000;
  transition: stroke-dashoffset 0.8s;
}
svg:hover .icono-hover {
  stroke-dashoffset: 0;
}

La animación se activa al verla

Receta 2: Animación al Aparecer 🌟

Usa JavaScript y `IntersectionObserver` para que la animación se dispare solo cuando el elemento es visible en pantalla. Perfecto para logos e infografías.

const elemento = document.querySelector('#miElemento');
const longitud = elemento.getTotalLength();

elemento.style.strokeDasharray = longitud;
elemento.style.strokeDashoffset = longitud;

const observer = new IntersectionObserver((entries) => {
  if (entries[0].isIntersecting) {
    elemento.style.transition = 'stroke-dashoffset 2s';
    elemento.style.strokeDashoffset = 0;
    observer.unobserve(elemento);
  }
}, { threshold: 0.5 });

observer.observe(elemento);

Haz scroll en esta área

Receta 3: Progreso Sincronizado 🚀

La animación está conectada a la barra de scroll. Si avanzas, se dibuja; si retrocedes, se borra. El efecto "premium" para storytelling visual.

const linea = document.getElementById('linea-progreso');
const longitud = linea.getTotalLength();
linea.style.strokeDasharray = longitud;
linea.style.strokeDashoffset = longitud;

window.addEventListener('scroll', () => {
  const progreso = scrollTop / (scrollHeight - clientHeight);
  linea.style.strokeDashoffset = longitud - (longitud * progreso);
});

Galería de Inspiración

La técnica es increíblemente versátil. Aquí tienes algunas ideas para encender tu creatividad y ver dónde puedes aplicar estas animaciones.

✅

Iconos de UI/UX

Da vida a tus iconos. Un "check" que se dibuja al completar una tarea o un menú hamburguesa que se transforma en una "X".

✏️

Bordes de Formularios

Cuando un usuario selecciona un campo, el borde puede dibujarse alrededor para indicar que está activo y guiar la atención.

✨

Animación de Logos

Un uso muy popular es hacer que el logo de tu sitio se dibuje solo al cargar la página. Causa una primera impresión profesional.

📊

Visualización de Datos

Haz que las líneas de una gráfica se dibujen al verlas. Esto ayuda a dirigir la atención y a hacer los datos más digeribles.

✍️

Efecto de Escritura

Convierte una firma o frase manuscrita en SVG y anímala para que parezca que se escribe en tiempo real. Un toque muy personal.

🗺️

Rutas en Mapas

Anima una línea que traza una ruta de viaje, el recorrido de un paquete o la conexión entre dos puntos en un mapa.

Consejos Profesionales

Para llevar tus diseños al siguiente nivel, ten en cuenta estas buenas prácticas.

Optimiza con SVGOMG

Antes de usar un SVG, pásalo siempre por la herramienta online SVGOMG. Limpia y optimiza el código, haciéndolo mucho más ligero sin perder calidad. Es un paso indispensable.

Piensa en la Accesibilidad

Si la animación es puramente decorativa, añade aria-hidden="true" a la etiqueta <svg>. Esto evita que los lectores de pantalla intenten leer el código del gráfico, mejorando la experiencia para usuarios con discapacidad visual.
