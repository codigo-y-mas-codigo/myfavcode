Copiar y Pegar

Explicación:

El código HTML define dos campos de texto: uno para el dato a copiar y otro para el dato pegado.

Los botones "Copiar" y "Pegar" llaman a las funciones copiarDato y pegarDato respectivamente.

La función copiarDato usa la API de Clipboard para copiar el valor del campo "dato_copiar" al portapapeles. Luego, muestra un tooltip con un mensaje de confirmación.

La función pegarDato usa la API de Clipboard para obtener el valor del portapapeles y lo pega en el campo "dato_pegar".
