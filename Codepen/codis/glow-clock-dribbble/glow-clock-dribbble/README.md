# Glow Clock Dribbble

A Pen created on CodePen.

Original URL: [https://codepen.io/luisangelmaciel/pen/YPwMMdV](https://codepen.io/luisangelmaciel/pen/YPwMMdV).

Based on this dribbble: https://dribbble.com/shots/2604410-Clock-Glow-Concept

While it's not exactly the same, I recreated the dribbble as closely as possible with the only dependencies being PrefixFree.JS, Conic-Gradient.js, and Google Fonts. The only image used in this entire Codepen is the background image on the clock face on the right, which belongs to Gleb Kuznetsov, the creator of the original Dribbble.
