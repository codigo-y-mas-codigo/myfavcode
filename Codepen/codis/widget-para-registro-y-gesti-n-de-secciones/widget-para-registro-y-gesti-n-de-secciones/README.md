# Widget para Registro y Gestión de Secciones

A Pen created on CodePen.

Original URL: [https://codepen.io/luisangelmaciel/pen/WNBoOzJ](https://codepen.io/luisangelmaciel/pen/WNBoOzJ).

Este widget  permite registrar, editar, borrar y gestionar secciones de contenido dinámicamente. Los datos se almacenan en localStorage, pueden descargarse en formato JSON y copiarse al portapapeles.
