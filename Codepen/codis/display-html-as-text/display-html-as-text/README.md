# Display HTML as text

A Pen created on CodePen.

Original URL: [https://codepen.io/luisangelmaciel/pen/BaeWbEp](https://codepen.io/luisangelmaciel/pen/BaeWbEp).

This pen takes the content of the first code element, and by interepreting the DOM of the element it replaces the rendered elements with the raw HTML code. It also adds some style to it.
