Efecto de degradado en CSS


Para que el truco de dibujar líneas con desplazamiento de guión funcione, necesitas tener una "línea" que consista solo en un trazo. Sus líneas de vapor son en realidad formas cerradas, donde el camino discurre por el exterior de la línea. Entonces, en lugar de obtener el efecto de vapor que desea, obtendrá una línea animada que recorre el exterior de la línea de vapor. Ejemplo de un efecto en CSS Linear Gradient Multiple Stops.
